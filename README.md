# Bike Sharing Analytics Dashboard 🚲

Proyek Analisis Data ini bertujuan untuk mengeksplorasi pola peminjaman sepeda berdasarkan kondisi cuaca, musim, serta suhu udara, lengkap dengan dashboard interaktif berbasis Streamlit.

## Setup Environment (Lokal)

1. Buka terminal/command prompt di folder proyek.
2. Install pustaka yang dibutuhkan menggunakan perintah:
   ```bash
   pip install -r requirements.txt
   ```
